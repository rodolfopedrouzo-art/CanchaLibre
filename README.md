# CanchaLibre
Trabajo Práctico - Sistema de reserva de canchas deportivas

Descripción:
CanchaLibre es un sistema pensado para gestionar la reserva de canchas deportivas, permitiendo registrar clientes, realizar reservas, consultar canchas y actividades, gestionar pagos y cancelaciones.

Contenido:
- Historias de usuario
- Tablero Kanban
- Diagramas de Flujo de Datos
- Diagrama Entidad-Relación (DER)
- Diagrama de Clases UML
- Documentación del sistema
